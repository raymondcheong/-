# 智能订单数据分析助手

在订单明细 Excel 基础上，按**客户属性**做两类分析：

1. **产品销售分析**：指定客户属性（如「凍肉店」）后，统计各「小类」的金额、箱数及占比  
2. **下单时段偏好**：指定客户属性后，基于「创建时间」判断更偏向几点到几点下单

## 字段约定

| 含义 | 列名（兼容简繁体） |
|---|---|
| 客户属性 | `客户属性` / `客戶屬性` |
| 金额 | `订单总金额` / `訂單總金額`（多商品订单按 `销售数量` 分摊到行） |
| 产品 | `小类` / `小類` |
| 箱数 | `销售数量` |
| 下单时间 | `创建时间` |

## 文件说明

- `智能订单数据分析助手.dsl.yaml`：可导入 Dify 的完整 Chatflow DSL  
- `智能订单数据分析助手.dsl(1).yaml`：同上（兼容原文件名）  
- `analyze_customer_attr.py`：本地直接对 Excel 跑分析的脚本（推荐大数据量场景）

## 本地运行

```bash
pip install openpyxl
python analyze_customer_attr.py "/path/to/订单.xlsx" --sheet 订单列表 --attr 凍肉店 --mode both
```

## Dify 导入

1. 在 Dify 工作室选择「导入 DSL」  
2. 上传 `智能订单数据分析助手.dsl.yaml`  
3. 按环境重新选择「提取分析参数」「结果解读」节点的模型  
4. 上传订单 Excel，提问例如：  
   - `分析凍肉店各产品的金额、箱数及占比`  
   - `凍肉店更偏向于几点到几点下单`

> 说明：仓库中未包含原始 `智能订单数据分析助手.dsl(1).yaml` 附件，本目录文件按该助手能力需求与现有订单表结构重建，并新增上述两个客户属性分析能力。
