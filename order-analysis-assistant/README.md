# 智能订单数据分析助手

## 数据源

默认使用清洗版订单 CSV（需包含 **`客戶屬性`**、**`创建时间`** 列）：

- 本地原文件示例：`C:\Users\admin\Desktop\智能体\区分客户自助下单_清洗版1.csv`
- 仓库内副本：`order-analysis-assistant/data/区分客户自助下单_清洗版1.csv`

> 云端环境无法直接读取你电脑桌面路径；请把该 CSV 放到上述 `data/` 目录，或运行时传入路径。

## 分析能力

1. **客户属性 × 产品销售**  
   按 `客戶屬性` 筛选（如凍肉店），统计各 `小类` 的金额、箱数及占比。  
   - 金额：`订单总金额` / `訂單總金額`（多商品订单按 `销售数量` 分摊）  
   - 箱数：`销售数量`

2. **客户属性 × 下单时段**  
   按 `客戶屬性` 筛选后，基于 `创建时间` 统计小时分布，给出更偏向的几点到几点。

## 字段约定

| 含义 | 列名 |
|---|---|
| 客户属性（必填维度） | `客戶屬性` / `客户属性` |
| 下单时间（时段分析必填） | `创建时间` |
| 产品 | `小類` / `小类` |
| 箱数 | `销售数量` |
| 金额 | `訂單總金額` / `订单总金额` |

## 本地运行

```bash
# 查看客戶屬性可选值
python analyze_customer_attr.py data/区分客户自助下单_清洗版1.csv --list-attrs

# 凍肉店：销售 + 下单时段
python analyze_customer_attr.py data/区分客户自助下单_清洗版1.csv --attr 凍肉店 --mode both

# 若使用你桌面原文件（在本机执行）
python analyze_customer_attr.py "C:\Users\admin\Desktop\智能体\区分客户自助下单_清洗版1.csv" --attr 凍肉店 --mode both
```

仓库中的 `data/区分客户自助下单_清洗版1.csv` 由现有订单 Excel 清洗生成：规范化 `客戶屬性`、格式化 `创建时间`。若你本地清洗版内容更新，请覆盖该文件后再分析。
